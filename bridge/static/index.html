Connect an AI agent

MCP over HTTP. Tools: measure, configure, get_reading, get_state, scpi.

claude mcp add --transport http metermind http://HOST/mcp

Other MCP clients: Streamable HTTP at http://HOST/mcp.

Status LED

Blue, blinking setup mode: join MeterMind-XXXX
Yellow connecting to WiFi (blinking: trying a new network)
Orange on WiFi, meter not answering
Green running
Cyan blink a new reading
Red, blinking meter USB power overloaded (over 0.5 A)
White BOOT held

On the board

Antenna end up, buttons on the left edge.
BOOT (upper): hold 3 s to open WiFi setup, MeterMind-XXXX. Hold 3 s again to close it.
RESET (lower): restarts. Settings are kept.
USB-C: power (5 V, 1 A or more) and a serial console at 115200 baud; type help. USB-A: the meter.
